# 工作流暂停态持久化测试用例（测试工程师参考）

## 依据与范围

- 已确认规格：[spec.md](./spec.md)，2026-11-25 用户确认版。
- 设计复查：design.md 2026-11-25 用户确认版；无需调整用例。
- 目标版本与构建：v3.1.0 / 分支 `fix/3.1.0/workflow-pause-persist`（基线 `3f61dab71d`），尚无构建（待实现）。
- 其他依据：workflow-study 联调脚本 `b1b.py` 的暂停、重启 Worker、续跑场景（修复前稳定复现 10541）。
- 代码核对：已核对 `worker/workflow/tasks.py`、`workflow/graph/graph_engine.py`、`workflow/graph/graph_state.py`、`worker/workflow/redis_callback.py`；错误码 10544、10545 已核对未被占用。
- 覆盖范围：暂停、重启、续跑主链路；保留期与清理；并发、损坏、过期；两个入口的一致性。不覆盖运行中崩溃的恢复。

## 环境、账号与测试数据

| 代号 | 角色或数据 | 准备方法 | 确认方式或待确认项 |
| --- | --- | --- | --- |
| ENV | 隔离环境 | MySQL、Redis、OpenFGA 与本分支的 API、Worker；库结构需升级到本分支 | `GET /health` 返回 OK；Worker 日志出现 `ready` |
| U-RUN | 有工作流使用权限的用户或服务账号 | 平台账号，或带 `workflow:invoke` 的服务账号密钥 | 能调用 `POST /api/v2/workflow/invoke` |
| WF-PAUSE | 含一个输入节点、一个输出节点的工作流 | 开始、对话输入、输出（回显输入）、结束，并上线 | 首次调用返回 `input` 事件 |
| WF-LOOP | 多轮对话工作流 | 开始、输入、条件（输入“结束”则结束）、输出，输出连回输入 | 能连续暂停多次 |
| WF-VARS | 变量依赖工作流 | 开始、输入、LLM、输入、输出，第二次输出引用第一次 LLM 的结果 | 续跑后输出包含前一段的结果 |
