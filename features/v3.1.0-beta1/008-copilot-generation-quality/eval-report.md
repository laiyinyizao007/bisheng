**观察**

1. 现状从不先问：「应先问」组 15 次全部直接出方案（命中率 0%），硬性要求只有 40%（例如阈值写成 `greater_than`、没用发送邮件工具），走查 56%。
2. 「做不到」只有一半说明了：审批说明了（3/3），数据库写入一次都没说明（0/3），定时触发 2/3。
3. **工具参数名靠猜**：`clear-calculator` 3 次全部失败——三次尝试都把计算器的参数写成 `input`，平台校验「模板里没有参数 input」。原因是提示词的资源清单只给了工具名、没给参数名；已在方案 A（T005）里补上。
4. 修改已有画布表现稳定（全部 100%）。
