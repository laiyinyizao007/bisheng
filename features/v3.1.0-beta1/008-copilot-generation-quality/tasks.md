## 开发模式

- **先量后改**：Wave 1 先做评测并跑出现状基线，Wave 2 才动 copilot；Wave 3 再跑评测对比。
- **后端 / 前端**：Test-First，先写测试、看它红，再写实现；前端 vitest 只比新增失败。
- **评测**：调用真实模型、产生费用，只手动运行；结果文件不含令牌与密钥。
- **换行**：worktree 是 CRLF 检出（autocrlf），脚本改文件先转 LF 再转回；提交时由 git 归一为 LF。
- **设计论证**只写在 design.md，这里只写「做什么、改哪、验收」。
